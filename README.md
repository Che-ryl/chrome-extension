# Getting Started
Install the dependencies and run the project
```
npm install
npm start
```

## Chrome extension leads tracker
This is a solution to the [Chrome extension leads tracker project](https://scrimba.com/learn-javascript-c0v) on Scrimba.\
Visit [leads tracker](https://cozy-entremet-db69c2.netlify.app/).

## How to install
- Clone Repo or Download Zip
- Visit chrome://extensions/ and turn on "Developer mode"
- Click "Load unpacked" button and navigate to the folder you downloaded
- That's it! 🎉
